# Notas sobre STM32 y Sistemas Embebidos 🚀

Este repositorio es mi bitácora personal de aprendizaje sobre microcontroladores STM32 y el desarrollo de sistemas embebidos profesionales utilizando la placa **Nucleo-F439ZI**.

## 🛠️ Entorno de Desarrollo
- **MCU:** STM32F439ZI (Cortex-M4 @ 180MHz)
- **IDE:** STM32CubeIDE
- **Librerías:** STM32Cube HAL
